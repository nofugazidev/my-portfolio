# Portfolio Website

A minimalist and modern portfolio website built with React and Tailwind CSS.

## Features

- 🎨 Modern, minimalist design with dark theme
- 📱 Fully responsive layout
- ⚡ Smooth animations and transitions
- 🧭 Smooth scroll navigation
- 📧 Contact form
- 🎯 Active section highlighting

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- React Icons
- FormSubmit (for contact form - free, no API keys needed!)

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Contact Form

The contact form uses [FormSubmit](https://formsubmit.co/) - a completely free service that requires **no signup, no API keys, and no configuration**! 

The form is already configured to send emails to `oyebisimubarak4@gmail.com`. It works out of the box - just start using it!

If you want to change the recipient email, simply update the email address in `src/components/Contact.jsx` in the fetch URL.

## Customization

1. Update personal information in all components
2. Replace placeholder project data in `src/components/Projects.jsx`
3. Update social links in `src/components/Hero.jsx` and `src/components/Contact.jsx`
4. Adjust colors in `tailwind.config.js`
5. Add your own projects and experience details
